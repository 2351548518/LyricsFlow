# 罗马音补全与标注同步

日期：2026-11-03。

2026-11-04 阅读排布调整：罗马音放到对应原文上方，中文译文仍位于原文下方；与原文共用宽度、主题对齐设置和分组动画，间隔 5 dp。普通首页、全屏和自由排版共用同一实现。当前来源及模型响应是整句注音，未包含逐词对应位置，因此这里提供整句对齐，不猜测逐字映射。新增长句用例验证三种阅读模式的上下顺序及左右边界、关闭罗马音后保留原文和译文；罗马音及全屏共 10 项模拟器专项通过，Debug Lint 0 错误。

本次调整的正式签名 R8 本地包已覆盖安装 HONOR 真机并冷启动，查看了 LRCLIB 日文／中文／罗马音在首页和全屏中的顺序及左对齐，原有设置保留。Release Lint 0 错误、37 项警告。本地包保存在 `dist/romanization-above/`，版本号仍为 1.0.6，未替换 GitHub 已发布附件；截图只留本地。

- 首页“译”右侧增加“罗”，控制已有罗马音的显示，并在已授权时自动补全缺失注音。个性化设置使用同一开关。评论按钮统一为与翻译按钮相同的无底色图标按钮。
- 与在线翻译共用 HTTPS API、模型、加密保存的 Key 和发送歌词授权。只提交需要注音且标注为空的行；已有来源注音保留。日语使用 Hepburn，韩语使用 Revised Romanization，中文使用带声调拼音；拉丁文字无需再注音。
- 逐行校验响应 ID、完整性及拉丁文字格式，不改歌词原文或时间轴。切歌、关闭显示或撤回授权会取消旧的自动请求。失败不会无限自动重试，可关闭再开启重试。
- 译文和罗马音分别合并，防止两个请求回写时互相覆盖。按顺序、以 SQLite 事务更新歌词缓存及匹配的收藏副本；不同歌词记录不被旧标注替换。刷新同一记录时保留缺失的已有标注。
- 缓存与收藏的完整歌词 JSON 原已包括翻译和 `romanization`；现有歌词包、完整备份和 GitHub 私有快照上传／下载／恢复继续携带它们，Key 不进入快照。
