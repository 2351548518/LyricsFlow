# 封面与页面背景的连续过渡（2026-10-28）

## 原因与改动

原先只模糊独立矩形内的图片，矩形上下边缘仍完全不透明；底部平均色填充也遮住了整页网状渐变。网状渐变的聚类色不包含图片空间位置，大幅移动时尤其容易出现封面与周围颜色错位。亮色封面的白边会进一步放大矩形边界。

本轮改为：

- 图片使用两级模糊混合。中心保留用户设置的 0–24 模糊程度，四周渐渐混入更柔和的图片层；边缘模糊内部最多为 32。值为 0 时关闭两层图片模糊，但保留边缘融入背景的效果。
- 图片外沿以平滑曲线渐隐，顶部/底部过渡带最大 112 dp、且不超过高度 24%；左右最大 28 dp、且不超过宽度 9%。图片完全铺满，视觉上没有留白边框。
- 去掉图片底部独立的不透明均色矩形。渐隐处直接显露同一张页面背景，无需复制/对齐两个独立动画，边界不会随时间再次显露。
- 图片的模糊及透明遮罩仅作用于图片图层。歌词保持原分辨率、原有字号、左对齐、逐字效果及描边，不把整块歌词一起模糊。
- 48×48 封面采样改为四个重叠区域的加权 RGB 均值，保留左上/右上/左下/右下的颜色关系。原有全图精确 RGB 平均值仍用于整体主题与文字颜色。
- 渐变采用更宽的高斯权重混色，小幅控制点位移及较轻的坐标变形，避免颜色块大幅换位。保留 25% 离屏背景、约 30 Hz、生命周期/暂停/减少动态效果控制与文字对比度边界。

Android 12 及以上使用系统 GPU 图片模糊，旧版继续使用原有后台、有界、可取消的图片模糊回退；不需要 C++，不会在动画帧中重新扫描图片。官方图片模糊说明见 [Customize Images](https://developer.android.com/develop/ui/compose/graphics/images/customize#blur_an_image_composable)。

## 边界

图片中心仍然保留原封面颜色，不保证原图的每个局部像素都与文字达到固定对比度；继续使用原有歌词描边。四区域颜色是封面坐标关系，不是对手机/平板裁切后边缘像素的逐点复刻。极端白边或复杂封面在中心仍可辨识，这是保留原图而非把整个封面替换成渐变的结果。

两级模糊使用两张图片绘制层，属于额外 GPU 合成开销；不以视觉改动直接宣称性能提升。

- 模拟器使用既有固定样本，预热 5 秒、采集 25 秒：[基准执行](./artwork-blend/benchmark.log)、[gfxinfo](./artwork-blend/emulator-gfxinfo.txt)。1241 帧，252 帧被系统标记为卡顿（20.31%），P95 61 ms。上一轮同样本离屏版本为 17.50% / P95 61 ms；不是同时对照实验，不能认定全部差异来自本次改动，但模拟器仍未满足流畅度发布验收。
- 真机读取 30 秒 gfxinfo：[原始数据](./artwork-blend/real-gfxinfo.txt)。3174 帧，18 帧被标记为卡顿（0.57%），P95 8 ms / P99 16 ms。采样前后截图曲目不同，手机也正在被使用；这是混合播放/切歌环境的观察数据，不是固定首页/固定歌词的严格性能对照。没有据此声称性能提升或完成长期耗电验收。
