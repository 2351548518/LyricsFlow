# 流水主题与阅读空间调整

日期：2026-10-27。实现：原生 Jetpack Compose。图片验收素材中，模拟器使用程序绘制的测试封面和原创示例歌词；真机截图使用当时 Spotify 的真实播放状态。

## 行为

- 首页移除品牌／聆听栏；“我的”移除品牌栏、重复标题和宣传副标题，保留本地用户卡片及设置入口。子页面保留返回／帮助。
- 歌名由 31 sp 改为 25 sp，歌手由 11 sp 改为 15 sp；固定一行。仅溢出时向左滚动，速度 26 dp/s、首次和循环停顿 1.6 秒。减少动态效果时禁用跑马灯，完整文字仍在无障碍语义中。
- 四种固定配色新增“跟随封面”。RGB 分通道求算术均值，忽略全透明像素，以 Long 累加；后台分块扫描、弱引用缓存、位图 generationId 校验。硬件位图临时复制到可读位图并释放副本，不回收播放器原图。
- 用户反馈后修正整页接近白色的问题：跟随封面时背景仅混白 6%，深色模式压暗 8%，保持真实均色及轻微同色渐变；不再沿用固定配色的 94% 浅色底。均色混白 18%（深色 38%）只用于强调容器。文字／按钮单独校正对比度，无封面使用海蓝。
- 最新红框修订：手机歌词背景左右铺满，直角矩形、等比居中裁切，不留侧边色带；歌词正文与标题／歌手保持同一左边界，歌词源右侧倒三角移除。平板保留双栏，背景同样为直角。
- 图层顺序：主题底色 → 100% 封面 → 清晰歌词。移除整图明暗蒙层；从 ART／ALBUM_ART／DISPLAY_ICON 中选择最大位图。个性化新增模糊程度 0–24，默认 8，0 为原图；仅模糊封面与自定义图片，原始均色与文字不受影响。Android 12+ 使用原生图形效果，API 24–30 使用后台、最多 384 像素长边的兼容模糊及 80 ms 调节合并。兼容算法在现有设备验算，旧系统实体机尚未覆盖。
- 中文译文由约 13 sp 增至常规默认约 18 sp，最小 16 sp，行高为字号 1.4 倍；自由布局按有限分区调整，防止溢出。模糊设置持久保存并随备份导出／恢复；旧备份缺失该字段时保留当前设置。
- 歌词以封面 RGB 反色为起点，校正文字对均色的对比度，并以约 0.6 dp 的可见轮廓保护复杂纹理（底层居中笔画 1.2 dp）。无障碍树只暴露主文字，描边层不重复朗读。此方法不承诺照片每个局部像素都达到相同比值；当前行最突出，前后行仍可阅读。
- 主题文件的固定文字颜色在图片背景下由可读性规则替代；纯色背景继续遵循主题文件。配色与封面背景为独立设置，导入备份允许第五种配色。
- 固定配色保留静态水流曲线；跟随封面使用同色渐变，不掺入大片白色装饰。不启动常驻背景动画；系统栏图标根据实际背景亮度选择。

真机 HONOR 的 2048×2048 图多次首次扫描约 **15–22 ms**、缓存约 **0.002 ms**：[设备日志](./flow-ui/real-cover-timing.log)。计算在后台执行；该结果为单机开发版测试，不能外推所有设备。当前没有引入 JNI／NDK 的必要。该机 Spotify 元数据仅提供 **300×300** 封面；普通读取及 `loadThumbnail` 读取附带 URI 均返回 `FileNotFoundException`，未声称取得高清原图。

## 闪烁原因与修复

首页每 15 秒刷新播放会话，系统可能返回内容相同的新 Bitmap。旧 `rememberCoverAverage` 用 `key(bitmap, generationId)` 包住初始值为 null 的取色状态，导致每次更换对象先绘制默认主题、再绘制均色主题。切歌多次元数据更新会重复该过程；同曲封面短暂缺失还会显示占位插画。

修复保留当前取色，后台新结果就绪后才替换；真实缺图持续 500 ms 才清空。播放器同一曲目保留已有最高质量封面，换曲不会复用上一曲图片；空会话／空元数据设置 500 ms 稳定期，权限失效立即清空。设置字号、配色、模糊时不再无条件刷新播放会话，仅切换优先播放器才刷新。

回归用例连续替换四份相同封面，模拟短暂缺图、新封面和持续缺图；确认中间没有 null 取色帧，持续缺图才回退。另验证同曲缺图保留封面、低清图不覆盖高清图及换曲不继承旧封面。
