# 控件可读性与设置页面统一

日期：2026-10-27。范围：我的、个性化、播放／来源／翻译等设置、评论列表、歌曲匹配及歌词来源弹窗，沿用首页配色。

## 原因与实现

原先只替换了部分 Material 3 颜色角色，选中容器采用 15% 透明色，选中／未选中标签接近同色；边框、弹窗和其他容器继续使用默认色，说明文字又叠加了较低透明度。因此选项在中等亮度封面上很难辨认。

- `ControlColors` 生成不透明的文字、按钮、边框和分层容器颜色。普通文字／说明对比度至少 4.5:1，选中标签至少 7:1，交互轮廓至少 3:1；禁用图标和装饰分隔线不计入该边界目标。
- 完整映射 Material 3 容器、前景、边框及固定颜色角色；匹配弹窗采用同色系实体背景。封面在弹窗打开期间变色时，更新系统栏图标，不销毁重建窗口。
- 单选按钮：实色底、勾选、加粗标签及单选语义；未选中项使用清晰边框。覆盖排版、配色、显示模式、歌词／评论来源、热门／最新以及首页／我的导航状态。
- 开关：整行可点击，提供开／关文字、位置、图标及状态语义；不再只依赖微弱色差。
- 我的与设置项改为分层卡片；评论使用独立卡片、清晰作者／日期／热度文字，保留完整正文。头像按字素取首字符，不拆坏 emoji。
- 紧凑子页标题栏、清晰说明文字；平板阅读列居中并限制至 840 dp。首页全宽封面和歌词排布保持原有行为。
- 搜索进行时显示进度与“正在搜索…”，不可操作按钮仍保留可读文字。没有改变搜索、绑定、评论请求或翻译额度策略。
