# 三种文字独立字号

日期：2026-11-04。

个性化设置新增独立的原文、翻译和罗马音滑块。原文 16–48 sp，翻译 8–48 sp，罗马音 8–40 sp；预览使用三种实际字号。调整原文不再连带改变翻译字号。

首页、全屏、自由排版及三层词组对应统一读取这三项设置。当前行继续使用既有强调效果，自由排版仍受可用分区高度约束。主题导入时显式声明的翻译／罗马音字号作为设置导入，之后用户可通过滑块覆盖；主题颜色、字体和动画继续生效。

新增设置写入 SharedPreferences，随完整备份及 GitHub 快照保存恢复。旧备份缺少两项字段时，翻译从原文字号推算旧默认值，罗马音使用 13 sp；新备份恢复时分别校验范围和非有限值。

验证：

- 125 项模拟器默认回归全部通过，含新增 2 项：滑块与预览、独立调节、重启持久化、备份恢复及旧备份兼容；普通／全屏／自由阅读与词组单元的真实 TextLayout 字号检查。
- 47 项 JVM 通过；Debug／Release Lint 0 错误、37 项警告。
- 正式签名 R8 本地包已覆盖安装 HONOR 真机。实际 UI 树中可见三个独立字号控制，随后查看了阅读页的新字号效果；用户原数据未清除。截图及测试日志仅保留在忽略提交的 `dist/font-sizes/`。

当前是版本号仍为 1.0.6 的本地功能包，未替换 GitHub 的既有附件。
