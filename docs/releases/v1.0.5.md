# LyricsFlow v1.0.5

优化网络请求与内存使用，搜索候选时长更容易阅读，保留原有歌词和主题显示效果。

## 更新内容

- “寻找这首歌”的候选时长统一显示为分:秒，例如 `144 秒` 改为 `02:24`；QQ 音乐、网易云、AMLL 和 LRCLIB 使用相同格式。
- 切歌或取消搜索时，及时取消旧音乐接口请求、断开连接并丢弃迟到结果，减少无效读取与缓存写入。
- 修复接口触发限流后，有效本地缓存也无法读取的问题；显式刷新仍遵守服务端限流。
- LRCLIB 候选提示只保留简短文案，最多缓存 600 项，避免重复持有完整歌词响应；原文与罗马音提示规则保持一致。

## 验证与安装

功能改动已通过 47 项 JVM、115 项模拟器回归、15 项真机受控测试及 5 项真实联网检查；候选时长也已在真机确认。测试范围和性能样本的边界见[网络与内存记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.5/docs/android-qa/Network-Memory-Audit.md)及[时长显示记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.5/docs/android-qa/Candidate-Duration.md)。v1.0.5 的构建与升级验证见[发行记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.5/docs/android-qa/Release-v1.0.5.md)。
