# LyricsFlow v1.0.4

修复部分歌曲封面一直空白或呈灰色的问题，保持原有歌词、模糊与渐变显示效果。

## 封面恢复

- 支持播放信息中的封面 URI，兼容 Spotify 实际携带的 `transformation` 参数；本地 provider 读取失败时，用同一图片 ID 尝试官方图片 CDN。
- 增加会话与歌名匹配的音乐通知封面，以及严格核对歌名、歌手、版本和时长后的 QQ / 网易云封面补取。
- 灰色和透明占位图不再被当作成功封面，也不会覆盖同曲已有的有效图片；保留有明暗细节的正常黑白封面。
- 短期读取失败后继续前台低频重试；网络重新可用或点击首页来源右侧的圆形刷新箭头时，也会重试缺失封面。
- 成功封面按歌曲身份与图片地址缓存，限制为 64 个文件 / 32MB。切歌取消旧请求，避免旧封面覆盖新歌，也避免继续下载旧请求的后续地址。

封面补取不会改变歌词来源或已保存的匹配；不读取聊天通知正文，不使用 GitHub 或翻译凭证下载封面。
