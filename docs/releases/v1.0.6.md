# LyricsFlow v1.0.6

新增罗马音补全，让歌词阅读与注音切换更方便。

## 更新内容

- 首页“译”右侧新增“罗”按钮，独立控制罗马音显示；个性化设置也可切换。
- 已授权时，使用已配置的大模型 API 补全缺失注音，优先保留来源已有标注。日语使用 Hepburn、韩语使用 Revised Romanization、中文使用带声调拼音；拉丁文字无需重复注音。
- 模型返回结果校验行号、完整性和格式，不改原文或时间轴。切歌、关闭注音或撤回授权时取消旧的自动请求；失败后可关闭再开启重试。
- 译文与罗马音合并保存到歌词缓存及对应收藏，支持歌词包导入导出、完整备份和 GitHub 私有快照同步；刷新同一记录时保留已有标注。
- 评论按钮去掉填充背景，与翻译按钮使用一致的图标按钮样式。

罗马音与在线翻译共用服务、模型、API Key 和发送歌词授权，服务费用由提供者收取。模型注音可能存在读音误差。

## 安装与验证

下载 **`LyricsFlow-v1.0.6.apk`**，支持 Android 7.0 及以上，`versionCode = 7`。沿用首次发行的正式签名，可直接覆盖升级并保留本地数据，也可在“我的 → 检查更新”获取，最后由系统确认安装。

功能已在真机核验，协议、保存与同步往返使用受控数据验证，没有上传用户的实际快照。详细测试范围见[罗马音记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.6/docs/android-qa/Romanization.md)及[正式包发行验证](https://github.com/2351548518/LyricsFlow/blob/v1.0.6/docs/android-qa/Release-v1.0.6.md)。
