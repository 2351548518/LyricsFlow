# LyricsFlow v1.0.2

轻点首页歌词可展开为全屏阅读，只保留歌名、歌手和歌词。延续现有背景、译文、当前行高亮和滚动状态，展开与返回带动画；再次轻点歌词或使用系统返回即可退出。支持自由排版与减少动态效果设置。

个性化选项组改为等宽的单行布局，“保存来源设置”铺满整行。翻译移除每批 30 行／4,000 字符及单行 4,000 字符限制，一次处理当前歌曲全部缺失译文；官方 DeepSeek V4 模型的输出预算随输入长度增长，其他兼容服务使用服务端默认预算。

“跟随封面”和“专辑封面”分别排在配色与背景选项首位，保留原有配置值。本地歌词库的“删除”改为描边按钮，仍需确认后才移除收藏副本。

新安装默认使用“跟随封面、跟随系统、专辑封面”；已有明确保存的选择继续保留，旧备份缺少对应字段时采用新默认值。

在“我的 → 数据与支持”新增“检查更新”。点击后检查 GitHub 最新正式版，有更新时自动下载，校验完成后打开系统安装界面。

- 显示当前版本、下载进度及明确的检查结果，支持取消、失败重试、取消安装后继续安装。
- 公共 API 限流时使用官方 Release 页面与校验文件；支持通过官方附件 API 下载，减少部分网络无法连接下载页的影响。
- 校验 APK 大小、SHA-256、应用标识、版本和签名，仅允许同签名覆盖升级。
- 沿用现有正式签名与图标。更新无需 GitHub 登录，不影响已有歌词、设置和登录资料。

首次安装更新时，Android 8 及以上需要允许 LyricsFlow 安装应用；最后一步需在系统界面确认安装。

安装包：`LyricsFlow-v1.0.2.apk`，Android 7.0 及以上，`versionCode = 3`。从 v1.0.0 / v1.0.1 正式版直接覆盖升级，保留本地数据。模型自身的上下文和输出容量仍适用。

验证：44 项 JVM 测试、Release Lint、更新/全屏/布局/翻译专项测试及真机覆盖安装检查通过。
