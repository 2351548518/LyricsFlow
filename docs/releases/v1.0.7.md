# LyricsFlow v1.0.7

更方便地对照歌词、注音与译文，并减少备份同步中的重复工作。

## 更新内容

- 罗马音放在原文上方；支持原文、注音、中文按词语或短语对应，三层作为整体换行，首页与全屏阅读统一显示。关闭“罗”可回到整句排版，已有整句译文和来源注音保留。
- 个性化设置中，原文、翻译、罗马音分别调整字号，实时预览；新设置及词组对应随歌词、完整备份和 GitHub 快照保存恢复，兼容旧备份。
- 优化大模型提示词和响应校验：用编号范围还原原文，减少空格、标点或重抄差异导致的失败；逐行处理不合格分组，保留可用标注并回退整句，不因一行格式问题丢弃其他有效分组。
- 修复标注请求重复触发、等待期间沿用旧数据，以及切歌、修改服务配置或撤回授权后旧响应回写的问题；翻译和注音分别去重，较长注音请求读取超时设为 120 秒。
- 减少歌词渲染中的重复扫描与设置写入，保持现有强调效果。
- GitHub 同步直接校验 JSON 文件，预览与恢复复用解析结果；ZIP 导入只解压一次，上传预览减少临时对象占用。调整“包含背景”选项后，旧上传预览会失效，避免提交旧内容。

词组对应保留原文和真实时间轴，不生成虚构的逐词时间；不同语言可能按短语对应，模型读音与词义仍可能有误。在线服务仅在授权后调用，费用由所配置的服务提供者收取。

## 性能与验证

真机 Debug 合成备份测试，每组 5 次，使用同一轮旧链路对照：15 MB 本地预览编解码中位耗时约 **4.37 → 1.61 秒**，累计内存分配约 **525 → 170 MiB**。这仅包含本地编解码／校验，不包含网络、数据库读取，不等于常驻内存或耗电改善；详细方法和原始样本见[备份优化报告](https://github.com/2351548518/LyricsFlow/blob/v1.0.7/docs/android-qa/Backup-Codec-Optimization.md)。

功能阶段已通过 133 项模拟器回归、14 项真机备份与同步专项和 47 项 JVM 测试；模型响应及云端往返使用受控样例，不上传用户实际资料。正式包构建、签名及升级验证见[发行记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.7/docs/android-qa/Release-v1.0.7.md)。

## 安装

下载 `LyricsFlow-v1.0.7.apk`，支持 Android 7.0 及以上，`versionCode = 8`。沿用首次发行的正式签名，可覆盖升级并保留本地数据；也可从“我的 → 检查更新”获取，最后由系统确认安装。

`SHA256SUMS.txt` 用于核验 APK；`.cer` 附件是公开签名证书，无需安装到手机。
