# LyricsFlow v1.0.0

**让歌词，随音乐流动。** LyricsFlow 的首个正式版本，为 Spotify 等本机音乐 App 提供同步歌词、中文翻译和音乐评论阅读。

## 首版功能

- QQ 音乐 → 网易云 → AMLL → LRCLIB 四来源自动匹配，支持手动搜索、具体记录绑定与逐曲选择恢复。
- 双语歌词、当前行突出显示、真实逐字时间戳高亮、逐曲与逐来源时间校准。
- 用户自配 OpenAI 兼容翻译服务，补齐缺失中文译文；应用内每日不限量，第三方服务费用依提供者规则。
- QQ 音乐、网易云热门及最新评论，独立于歌词绑定。
- 随封面取色、动态网状渐变、渐进柔化封面、自定义排版与声明式主题。
- 可调字号、字体颜色、0%–100% 背景不透明度的双语悬浮窗，支持拖动、调整宽度、锁定穿透和关闭。
- 本地歌词库、导入导出与备份；可选 GitHub Device Flow 登录及专用私有仓库手动快照同步。
- 全新淡蓝色渐变 Logo，三条等长歌词波线；适配自适应、圆形及系统单色图标。

## 稳定性修复

修复旧搜索结果跨歌曲残留、评论匹配改写歌词绑定、收藏状态恢复与异步串歌、跨来源翻译回写，以及预览模式残留状态。来源切换失败保留当前可用歌词，刷新固定当前来源的记录。

## 下载与安装

下载附件 **`LyricsFlow-v1.0.0.apk`**，支持 Android 7.0 / API 24 及以上。`SHA256SUMS.txt` 用于校验下载完整性；`.cer` 是公钥证书，无需安装。

首次使用在“我的 → 播放与悬浮窗”授予通知使用权，然后在本机音乐 App 播放。悬浮窗另需显示在其他应用上层权限。翻译和 GitHub 同步均为可选功能。

**调试版迁移：** 正式签名与此前调试版不同，不能直接覆盖。先在旧版导出本地备份或完成 GitHub 同步，再卸载旧版、安装正式版并恢复。API Key、GitHub 登录及系统权限需重新配置。今后正式版会沿用同一签名。

## 支持边界

- 本应用不播放或下载音乐，不支持评论发布或点赞。
- QQ／网易云使用非官方公开接口；社区收录、平台变更、地区与网络可能影响搜索、歌词或评论。可切换来源或手动匹配。
- 同步精度取决于本机播放器提供的进度；远程 Spotify 播放不在支持范围内。
- 没有真实逐字时间戳时按行同步；来源没有原文、译文或罗马音时不会凭空生成对应内容。
- GitHub 同步为用户主动操作的快照，不是后台自动同步；恢复时同 ID 采用云端版本，并保留恢复前备份。

## 发行验证

正式包已通过签名与非调试标志检查、42 项 JVM 单测和 Release Lint；独立测试设备验证了冷启动、预览、歌词保存、设置、同签名覆盖安装后的数据保留，以及网易云真实歌曲、歌词和热门评论链路。既有版本的 70 项设备回归和真机记录见仓库验收文档。首版 APK 约 1.68 MiB，启用 R8 优化。
