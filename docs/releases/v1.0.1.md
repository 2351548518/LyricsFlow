# LyricsFlow v1.0.1

本次更新调整应用图标与品牌配色。

- 参考用户提供的蓝色图标，背景改为天蓝 `#40B4F8` 到亮蓝 `#285DF2` 的渐变。
- 三条歌词波线完全等长、同形、等距，统一使用浅冰蓝 `#E0F2FF`。
- 更新自适应图标、各密度普通/圆形图标、Logo 与 README 横幅。

下载 **LyricsFlow-v1.0.1.apk**，支持 Android 7.0 及以上。包名与正式签名延续 v1.0.0，versionCode 递增到 2，可直接覆盖 v1.0.0 正式版，保留本地数据。此前调试签名版本仍需先备份后迁移。

附件包含 APK、SHA-256 校验和及公钥证书（无需安装证书）。歌词、评论、翻译与同步功能沿用 v1.0.0，本次没有功能逻辑修改。
