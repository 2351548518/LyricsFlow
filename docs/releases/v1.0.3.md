# LyricsFlow v1.0.3

本次更新保持现有歌词、封面渐变和全屏动画效果，重点减少空闲开销、优化内存并修复导出与悬浮窗更新问题。

## 优化与修复

- 暂停首页停止无变化的时钟轮询；悬浮窗暂停或隐藏时等待状态事件，播放时保持原来的更新频率。
- 悬浮窗及时响应屏幕与权限变化，修复部分原文、译文或逐字数据变化后未及时更新的问题。
- 缓存歌曲和歌词指纹，加快当前歌词定位，减少重复计算；保留重复时间、无时间和乱序歌词的处理语义。
- 播放会话刷新时保留已有回调，减少反复注销、注册的开销。
- 导出改用私有文件暂存与流式复制，减少系统保存框打开期间的内存占用，避免界面重建后写出空文件；完成或取消后清理暂存。
- 内存回收时可释放 AMLL 解析索引，后续从磁盘缓存恢复，保留离线重试规则。

## 验证

47 项 JVM 测试、96 项模拟器回归测试全部通过，Debug / Release Lint 无错误；已完成正式签名真机覆盖安装与播放检查。

模拟器同一暂停示例、同一悬浮窗场景，排除系统栏后截图逐像素一致。约 30 秒采样的主线程调度运行片段从 966 次降为 7 次；这是特定空闲场景的观测结果，不能直接换算为电池耗电降幅。完整条件与限制见[性能检查记录](https://github.com/2351548518/LyricsFlow/blob/v1.0.3/docs/android-qa/Performance-Audit-v1.0.3.md)。
